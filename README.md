# ecm-rfi-template

A lightweight, HTMX-powered template for generating Requests for Information (RFI) specifically tailored for implementing Microsoft 365 Document Management Solutions.

## Purpose
This tool helps organizations standardize the process of querying vendors on their ability to implement Enterprise Content Management (ECM) solutions within the Microsoft 365 ecosystem.

## Features
- **HTMX Driven**: Fast, interactive, and entirely client-side or via simple partial loads.
- **GitHub Pages Ready**: Deployable as a static site without any backend server.
  
## How to Use
1. Clone this repository.
2. Browse the components in `/components`.
3. Customize questions to suit your specific organizational needs.
4. Host on GitHub Pages by enabling it in your repo settings.
